# 符号跨域映射工作台

日期: 2026-08-10
用途: 把传统符号转成现代系统语言，作为拓展面候选
原则:
- 先保留传统本义，不替代原文。
- 现代映射是“结构类比”，不是物理或历史结论。
- 每个映射可写假设，可验证则验证，不可验证则明标。

## 解码模板

1. 符号本义
2. 结构功能：存储 / 流动 / 收束 / 发散 / 转换 / 连接
3. 现代系统对应
4. 可验证假设
5. 边界

## 十二地支首批映射（候选）

| 地支 | 传统本义 | 结构功能 | 现代系统对应 | 可验证假设 |
|---|---|---|---|---|
| 子 | 水、种子、子时 | 流动、潜藏、初始 | 数据流、增量输入、基因信息 | 输入端越活跃，系统后续越多样 |
| 丑 | 土、金库、丑时 | 收纳、冷储 | 冷存储、档案库、底层设施 | 冷数据沉淀越多，系统越稳但越慢 |
| 寅 | 木、生发、寅时 | 启动、生发 | 创新引擎、启动器、新协议 | 新入口出现时，系统结构最易变化 |
| 卯 | 木、繁茂、卯时 | 并行、扩散 | 并发进程、内容生产、生态增长 | 并发越高，短期产出越多，越易失序 |
| 辰 | 土、水库、辰时 | 大库、蓄水 | 云存储、缓存池、蓄水池 | 缓存充足时系统平滑，缓存被冲时波动 |
| 巳 | 火、信息、巳时 | 连接、发热 | 网络流量、即时通讯、热数据 | 连接密度越高，信息传播越快 |
| 午 | 火、高峰、午时 | 显象、峰值 | 热榜、直播、峰值计算 | 峰值过后热度衰减最快 |
| 未 | 土、木库、未时 | 成果沉淀 | 作品库、知识库、归档 | 沉淀越多，越容易形成长期资产 |
| 申 | 金、传送、申时 | 规则、传输 | 协议、流程、制度 | 规则越清晰，系统越可复制 |
| 酉 | 金、精密、酉时 | 加工、精炼 | 编译器、芯片、精加工 | 精密层出错成本最高 |
| 戌 | 火库、戌时 | 平台、收束 | 平台池、用户池、闭环 | 池子越大，封闭越强，开库冲击越大 |
| 亥 | 水、源头、亥时 | 混沌、潜在 | 原始数据、未分化需求 | 混沌层越深，越难直接量化 |
