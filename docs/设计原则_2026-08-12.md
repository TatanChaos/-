# 颐真书房系统设计原则

状态：内部设计约束，用于判断新增功能、页面、文案和视觉是否进入标准版。
原则来源不是“塞金句”，而是把经史子集佛道里可操作的思想转成系统规则。

## 1. 少则得，多则惑

对应设计：

- 主导航只保留极少数主入口，不把全部功能平铺。
- 次要功能进“模块目录”，不抢主线。
- 一个页面只解决一件事。

来源思想：道家“少则得，多则惑”；儒家“知所先后，则近道矣”。

## 2. 物有本末，事有终始

对应设计：

- 五层路线：入门 → 深读 → 排盘 → 验证 → 收心。
- 内容统一按“原文 → 结构 → 生活 → 验证 → 留白”组织。
- 样本和稽古放在排盘之后，表示“先有候选，再回填验证”。

来源思想：《大学》“物有本末，事有终始”；《周易》“易简而天下之理得矣”。

## 3. 知止

对应设计：

- 不无限堆功能；候选功能先入草稿，经过稽核和真实样本后才进公开版。
- 页面停在该停的地方，不做无意义的展开。
- 正式版 v1 未满足条件前保持关闭，不用“画饼”充数。

来源思想：《大学》“知止而后有定”；《道德经》“知足不辱，知止不殆”。

## 4. 致中和

对应设计：

- 色彩克制，留白优先，动效只用于状态变化。
- 不采用扫描线、发光、强斜切等喧宾夺主的视觉。
- 每个界面先保证可读，再谈风格。

来源思想：《中庸》“致中和，天地位焉，万物育焉”。

## 5. 清静

对应设计：

- 页面不主动制造焦虑、紧迫感或“错过就没了”的压力。
- 深解前先提供静观入口，但不把静观包装成神通。
- 界面噪声越低，越适合长期阅读和反复使用。

来源思想：《太上老君说常清静经》“人能常清静，天地悉皆归”。

## 6. 无住

对应设计：

- 所有盘面、断语、系统映射都是“拓展面候选”，不挂死结论。
- 不执著于“算准”，不承诺预测结果。
- 真实样本回填后只更新验证状态，不把候选伪装成定论。

来源思想：《金刚经》“应无所住而生其心”。

## 7. 观照

对应设计：

- 用户看到的每一层，都标注“它是什么、怎么用、怎么验证、边界在哪”。
- 不替用户做决定，只把结构拆出来，留白给用户自己落笔。

来源思想：佛家观照、道家返观内视，以及“为学日益，为道日损”的减担原则。

## 判定清单

新增功能或页面时，先回答：

1. 它属于五层路线中的哪一层？
2. 如果不属于主线，是否能收进模块目录？
3. 这个页面第一眼最该让用户做什么？
4. 是否引入了噪声、焦虑、营销感或伪权威？
5. 是否保留了候选、验证和边界？
6. 如果不满足上述条件，先放草稿，不进公开版。
