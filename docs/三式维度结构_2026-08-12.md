# 三式维度结构

状态：内部结构说明，用于判断三式页面应该展示到几维。
目的：不是把 4D 画成平面，而是把空间、时间、状态分开表达。

## 太乙

- 二维：九宫盘。
- 三维：地盘 + 天盘 + 算局轴。
- 第四维：时间局、主客状态、定算。

页面呈现：九宫作为底，天盘作为第二层，主客算/定算作为状态读数。

## 奇门

- 二维：洛书九宫。
- 三维：九宫空间 + 门、星、神、干属性层。
- 第四维：年、月、日、时四层时间。

页面呈现：四层时间盘沿 Z 轴堆叠，每层是同一套九宫坐标；滑杆切换当前时间层。

## 六壬

- 二维：天地盘。
- 三维：天地盘 + 四课 + 三传路径。
- 第四维：720 课体状态空间、月将加时、旬空/神煞。

页面呈现：天地盘作为底，四课作为中间状态层，三传作为向上展开的路径。

## 4D 不是真画 4D

现实界面无法直接显示四维几何。我们的做法是：

- Z 轴：结构层。
- 时间轴：滑杆或动画切换。
- 状态轴：课体、局数、神煞等标签。

这样用户看到的是“可旋转的空间 + 可切换的时间 + 可读取的状态”，不是一张压平的图。
