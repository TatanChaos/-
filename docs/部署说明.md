# 标准版 v0.3 · 部署说明

目标：把标准版 v0.3 作为唯一公开版本部署。

## 推荐方案：Node 服务端

```bash
node server.js
```

适合部署到一台能跑 Node 的服务器或本地长期运行。

公开前需要：

- 域名或公网 IP
- 反向代理：Nginx / Caddy / Cloudflare Tunnel
- 端口 8780 对外开放
- 数据目录 `data/` 不入 Git，不上传到公开仓库

## 方案 B：静态托管

GitHub Pages、Vercel、Netlify 可以托管页面，但以下功能需要服务端：

- 组合盘服务端分页
- 八字排盘
- 黄历接口
- 样本箱
- AI 深解

如果先做静态公开版，这些功能会回退到本地规则或显示不可用。
