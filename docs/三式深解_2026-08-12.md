# 三式深解 · 颐真初笺

日期：2026-08-12
性质：面向大众的深层理解，非定论
方法：本义 → 天象 → 地象 → 人象 → 体 → 用 → 过 → 现代 → 生活 → 验证 → 落款

## 太乙

- 本义：太一即北天极，是古代天文观测的统一原点；太乙行九宫，表示气在时空中的运行位置。
- 天象：以北斗与北天极为基准，星官随天旋转。
- 地象：九宫分野，九州大地按方位承接天气。
- 人象：一个人先找到自己的“原点”，再看自己落在哪个位置。
- 体：太乙是坐标系统，主天时，主大局。
- 用：定基准、算局数、分主客、看当前局面的力量结构。
- 过：太乙过算则僵，只算局数，不问现实，会变成数字游戏。
- 现代：统一坐标系、全局定位、主客力量分析。
- 生活：做重要决定前先定原点，再判断自己处在哪个阶段。
- 验证：同一事件、同一历法口径排盘，结构应可复现。
- 落款：你做决定前，有没有先找到自己的“北天极”？

## 奇门

- 本义：洛书九宫为基础，把时间、方位、角色放进九宫格；值符代表主控，值使代表通道。
- 天象：九星在天，随节气运转。
- 地象：九宫在地，对应八方与中土。
- 人象：一个人面对一个局面，需要找到负责人、通道和障碍。
- 体：奇门是时空决策盘，主地利，主当前布局。
- 用：看九宫落位、门星神格局、四层时间盘、空亡与马星。
- 过：奇门过玄则迷，只看格局，不问行动，会变成地图上的困局。
- 现代：沙盘推演、角色网格、关键路径分析。
- 生活：选方向、看位置、找通道、判断什么时候动。
- 验证：同一事件、同一置闰口径排盘，结构应可复现。
- 落款：你面对的局面里，谁是值符，哪里是值使，哪里是空亡？

## 六壬

- 本义：月将加时建立天地盘，四课给环境信息，三传给演变路径；720 课表固化不同干支组合的结构。
- 天象：月将随月推移，代表当月的天区基准。
- 地象：十二地支环列，天地盘相对转动。
- 人象：一个人问一件事，事情从起点、经过路径、到结果。
- 体：六壬是事态路径系统，主人事，主进程。
- 用：看四课输入、三传路径、课体类型、神煞与空亡。
- 过：六壬过繁则滞，只背课体，不接现实，会变成路径迷宫。
- 现代：流程链、路径推演、状态机。
- 生活：一件事怎么走、卡在哪、会往哪落。
- 验证：同一时间、同一流派口径排盘，课体与三传应可复现。
- 落款：你现在这件事，起点是什么，路径卡在哪，落点像什么？

## 三式合参

- 太乙看天时：这个时间点的整体坐标。
- 奇门看地利：当前局面的空间布局。
- 六壬看人事：这件事从哪来到哪去。

三者不是三个答案，是同一个局面的三面镜子。
