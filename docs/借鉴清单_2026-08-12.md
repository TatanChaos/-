# 开源借鉴清单

日期：2026-08-12
性质：记录我们向开源项目学习的技术、数据口径和信息架构，不把别人的断语当作自己的原文。

## 已吸收

- `lunar-typescript`：八字排盘历法计算，接入本地 `/api/bazi`。
- `cnlunar`：农历、干支、黄历口径参考，用于对照历法实现。
- `suangua`：古籍 RAG 检索思路，对应我们的本地知识库 skill 与稽古审计。
- `xuanxue-database-skill`：个人样本库/回测概念，对应我们的本地样本箱与样本草稿。
- `Horosa-Web`、`Yunora` 等：信息架构与复杂数据展示方式，对应卡面折叠、筛选、状态标签。

## 未吸收

- 算命式断语。
- AI 生成但无法追到原文的解释。
- 未注明许可或来源的代码。

## 边界

- 所有借鉴都以技术、数据结构、信息架构为主。
- 涉及干支、命理、术数的理解，仍以本地古籍原文和真实样本为准。
- 各项目具体许可以其仓库 LICENSE 为准。

## 对应文件

- 八字排盘：`排盘/八字.html`、`server.js`
- 本地知识库：`~/.codex/skills/local-knowledge-base/`
- 样本回填：`samples.html`、`data/samples-inbox.ndjson`
- 稽古审计：`tests/audit-sources.mjs`、`稽古.html`
