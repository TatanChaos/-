## 设计借鉴

学设计不是抄皮肤，是抓已经验证过的“判断方式”。

### Apple Human Interface Guidelines

- 学：信息层级、留白、状态明确、触控目标至少 44pt、动效只用于状态变化。
- 不学：为了“苹果感”而把一切改成白色玻璃卡片。
- 落到颐真：纸墨书卷仍是底色，但控件高度、可读字号、焦点状态按现代系统标准执行。

### 明日方舟 UI

- 学：复杂系统如何用层级和状态组织，而不是用大量文字堆在一起。
- 不学：扫描线、斜切、发光、闪烁这些战术外壳。
- 落到颐真：数据型工具页面保持安静、可扫描、状态一眼可读；花哨装饰已撤除。

### 书卷 / 中国美学

- 学：留白、印章、朱砂、墨色、旧金、松绿。
- 不学：古风模板、仿古装剧、把装饰铺满页面。
- 落到颐真：宣纸底、朱砂点题、留白给用户批注。

### 博物馆公版素材

- 学：用真实文化资源建立视觉可信度。
- 不学：拿图片当装饰，不交代来源。
- 落到颐真：Met Open Access 公版图已入 `assets/backgrounds/`，来源记录在 `assets/backgrounds/README.md`。

## 已吸收的 skill

- `frontend-ui-standards`：设计令牌、组件复用、布局关系，用于避免散落硬编码。
- `ui-aesthetic`：颐真书房的纸墨书卷气质约束，用于判断是否“符合主题”。
- `local-knowledge-base`：原文检索、行号引用、状态标注，用于所有内容稽核。
- `playwright`：真实浏览器验收，用于移动端溢出、控制台错误、交互状态检查。
- `imagegen / codex-gpt-image`：需要原创位图素材时才使用，不替代代码原生图形。

## 未吸收

- 算命式断语。
- AI 生成但无法追到原文的解释。
- 未注明许可或来源的代码。

## 边界

- 所有借鉴都以技术、数据结构、信息架构为主。
- 涉及干支、命理、术数的理解，仍以本地古籍原文和真实样本为准。
- 各项目具体许可以其仓库 LICENSE 为准。
