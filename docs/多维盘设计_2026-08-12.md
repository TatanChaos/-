# 多维盘设计

状态：三式页面实验层，使用 Three.js 本地渲染。
原则：不硬画高维几何，把每一维当成一条可读的轴。

## 维度定义

- 3D：空间，九宫或天地盘。
- 4D：时间，滑杆和运动标记。
- 5D：状态，课体、局数、神煞等标签。
- 6D：样本，真实回填数据点。
- 7D：口径，流派与历法差异。
- 8D：观察，不同观察尺度的坐标线。
- 9D：验证，候选与已验状态的坐标线。
- 10D：流转，整体盘面随时间/状态持续重排。

## 实现

- `assets/three.min.js`：本地 Three.js，离线可用。
- `sanshi/multi-dim.css`：多维盘样式。
- `sanshi/multi-dim.js`：Three.js 场景、时间滑杆、3D-10D 维度切换。

## 边界

三维以上的维度是概念轴，不是物理几何。
做得好不好，取决于用户是否能在同一画面里读到“空间、时间、状态、样本、口径、观察、验证、流转”。
