# 进门 · 颐真书房

> 谋事在人，成事在天。

## 这是什么

颐真书房是一个开源文化研究作品，把古代象数符号当作结构来读。它不是算命工具，也不是许愿池；它不承诺结果，只记录、对照和验证。

## 我们读什么

- 干支：系统角色与结构状态。
- 六合、三合、六冲、六害、三刑：关系模式。
- 太乙、奇门、六壬：时空结构推演。
- 现代系统映射：类比，不是定论。

## 黑话和人话

黑话保留，人话紧跟。每讲一个术语，尽量给出一句普通人能懂的结构解释；每给一个映射，都要标“候选”。

## 你怎么参与

1. 在沙盘里选一个场景。
2. 用推演随录记下时间、问题、观察。
3. 结果出来后，用四句话交回样本。

## 什么才算数

真实样本回填前，盘面、断语、映射都只是候选。我们不承诺结果，只记录结果。

“谋事在人”的意思是：你负责把问题、行动、结果如实记下。
“成事在天”的意思是：结果不由我们承诺，也不由盘面决定，只能由现实和时间来给。

## 边界

- 不作预测、医疗、法律、投资或重大决策依据。
- 所有内容均为“拓展面候选”。
- 不收集姓名、电话、微信号、住址。
