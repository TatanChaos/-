# 表达原则 · 大白话与专业话

日期：2026-08-11
性质：内容验收原则

## 总原则

每条内容都要同时给出：

1. 大白话：普通人不用查术语也能知道在说什么。
2. 专业话：学的人能检查、能对照原文。
3. 出处或边界：能站住的地方标出处，不能站住的地方标候选。

## 大白话要给够

- 第一句必须是普通人能读懂的句子。
- 允许用生活例子，但不能为了通俗失真。
- 删掉专业话之后，普通人仍然知道这件事大概是什么。

## 专业话要给够

- 术语必须保留，不能因为怕门槛就全删。
- 每个术语尽量带结构解释。
- 专业话负责精确，不负责吓人。

## 给到位

- 不为了通俗把内容讲浅。
- 不为了显得专业把内容讲玄。
- 同一个概念，大白话和专业话同时出现，互相对照。

## 验收标准

- 普通人读大白话，能说出“这是什么、和我有什么关系”。
- 研究者读专业话，能指出“这个说法有没有原文、属于哪一派”。
- 两边都说不清的，标“待复核”，不硬圆。
