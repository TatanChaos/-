# 表达原则 · 大白话与专业话

日期：2026-08-11
性质：内容验收原则

## 总原则

每条内容都要同时给出：

1. 大白话：普通人不用查术语也能知道在说什么。
2. 专业话：学的人能检查、能对照原文。
3. 出处或边界：能站住的地方标出处，不能站住的地方标候选。

## 大白话要给够

- 第一句必须是普通人能读懂的句子。
- 允许用生活例子，但不能为了通俗失真。
- 删掉专业话之后，普通人仍然知道这件事大概是什么。

## 专业话要给够

- 术语必须保留，不能因为怕门槛就全删。
- 每个术语尽量带结构解释。
- 专业话负责精确，不负责吓人。

## 给到位

- 不为了通俗把内容讲浅。
- 不为了显得专业把内容讲玄。
- 同一个概念，大白话和专业话同时出现，互相对照。

## 验收标准

- 普通人读大白话，能说出“这是什么、和我有什么关系”。
- 研究者读专业话，能指出“这个说法有没有原文、属于哪一派”。
- 两边都说不清的，标“待复核”，不硬圆。

## 融会贯通

经史子集不是四块装饰，是同一个结构：

- 经：《周易·系辞上》“书不尽言，言不尽意”，所以圣人立象以尽意；符号是语言到不了的地方的桥。
- 子：《老子》“有之以为利，无之以为用”；《庄子》“人皆知有用之用，而莫知无用之用也”。留白才有用，看似无用的文化知识要接回生活。
- 史：《春秋》笔法，微言大义，不把话说满，褒贬在留白处。
- 集：《文心雕龙·隐秀》“隐也者，文外之重旨者也”；作品的价值在读者自己落笔的地方。

合起来就是：我们给“有”，但“用”在“无”里。候选解给够，最后一句由本人落笔；真实样本回填，就是让“无”回到“用”。

## 留白 · 国画原则

- 天衣无缝不是目标。
- 墨要给够，但不能铺满。
- 留白不是空，是给观者落笔的位置。
- 候选解是墨，读者的解是留白处的笔意。

## 风格与 UI 的融会贯通

- 同一套语言：纸、墨、朱砂、旧金、松绿，不拼贴。
- 同一套节奏：留白、间距、标题层级一致，不靠塞满显得丰富。
- 每一页都有一条可走的路：从生活到符号，从符号到自己的解，从自己的解到样本。
- UI 不是装饰，是同一套思想的延续：有之以为利，无之以为用。
