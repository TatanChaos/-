# 系统当前状态

日期：2026-08-12
性质：本地标准版当前状态总览，用于快速确认“做到哪、没做到哪”。

## 硬件与算力

- 机型：MacBook Pro，`Mac17,9`
- 芯片：Apple M5 Pro，`arm64`
- 核心：15 核（5 Super + 10 Performance）
- 内存：24 GB
- 当前负载：由系统决定，服务进程平时不空转，只有自检/重活时拉满

已实现：

- `/api/hardware`：上报真实 CPU、内存、架构、核心数。
- `/api/benchmark`：服务端多线程 Worker 跑满所有核。
- 浏览器 Worker：组合盘和系统自检页可跑浏览器多核自检。
- 组合 Worker：`/api/combine` 输入超过 2000 个对象时自动切 `worker_threads`。
- `npm start`：`UV_THREADPOOL_SIZE=16`，Node 堆 4GB。

## 层级与主次

- 沙盘顶栏只留：版本入口、AI 深解、静观。
- 其余功能收进模块目录抽屉。
- 初始首页只留：自己解开自己、生活衔接卡、真实样本。
- 五层路线：入门 → 深读 → 排盘 → 验证 → 收心。
- 系统自检页可验证硬件、服务端 Worker、浏览器 Worker、组合 Worker。

## 设计原则

- `少则得，多则惑` → 主导航收窄。
- `物有本末，事有终始` → 五层路线。
- `知止` → 候选不成熟不进公开版。
- `致中和` → 安静界面，克制动效。
- `清静` → 不制造焦虑。
- `无住` → 断语全是候选，真实样本回填才算数。
