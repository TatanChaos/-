# 开发者指南

## 项目一句话

颐真书房是一个开源文化研究工具：把干支、六十甲子、纳音、关系、生活问题翻译成可验证的结构语言，不装大师，不做预测。

## 快速开始

```bash
node server.js
```

打开：

- `http://127.0.0.1:8780/入口.html`
- `http://127.0.0.1:8780/index.html`

## 四层架构

### 1. 内容层

- `assets/deep-data.js`：22 个干支深解
- `assets/jiazi-deep.js`：60 组甲子深解
- `assets/nayin-deep.js`：30 组纳音深解
- `docs/`：原文、精读、稽古、表达、部署、测试报告

### 2. 代码层

- `assets/combination-engine.js`：浏览器与 Node 共用组合引擎
- `index.html`：沙盘主逻辑
- `translator.html`：术语翻译
- `tests/`：校验脚本

### 3. 服务层

- `server.js`：静态服务 + API
- API：
  - `GET /api/status`：服务状态
  - `GET /api/audit`：出处审计
  - `POST /api/combine`：组合盘
  - `GET /api/bazi`：八字排盘
  - `GET /api/huangli`：黄历
  - `POST /api/ai`：AI/规则深解
  - `POST /api/samples`：样本箱
  - `GET /api/samples/export`：导出样本

### 4. UI 层

- `index.html`：标准版主沙盘
- `入口.html`：标准版唯一公开入口
- `ai.html`：AI 深解
- `huangli.html`：黄历
- `稽古.html`：稽古状态
- `samples.html`：真实样本

## 测试

```bash
npm run all
```

包含：

- 内容完整性校验
- 服务冒烟测试
- 稽古审计

## 内容原则

- 每一条解释必须能追到原文或明确标为初笺。
- 真实样本回填前不视为已验证。
- 不收集姓名、电话、微信号、住址。
- 不伪造样本、不假装进化、不装大师。

## 贡献方向

- 古籍原文对校
- 真实样本整理
- 组合规则扩展
- UI 可读性
- 多语言翻译
- 服务端部署
