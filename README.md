# 颐真书房 · 符号映射沙盘

一个认识自己的文化研究工具：不替你解命盘，教你自己把自己解开。

## 这是什么

- 一个可交互的干支符号沙盘：地支六合、三合、六冲、六害、三刑，以及天干五合。
- 生活衔接卡：12 类现实事件，从生活进入符号。
- 自己解开自己：自读五步 + 公开知识。
- 真实样本站：四句话提交，真实结果回填。
- 八字排盘：支持出生时间输入，本地历法库计算。
- 一份“拓展面候选”文档：把传统本义转成结构功能、现代系统对应、可验证假设。
- 所有内容均为文化研究底稿，不是命理定论，不作预测、医疗、法律、投资或重大决策依据。

## 定位

- 不是许愿池，是样本站。
- 大白话和专业话同时给够、给到位。
- 候选解给够，留白给读者自己落款。
- 真实样本回填前，一切视为候选。

## 运行

本目录是纯静态网页，直接打开 `index.html`，或在目录内启动本地服务：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 边界

- 现代系统映射全部属于“拓展面候选”，不冒充物理或医学结论。
- 可验证假设需要真实样本回填，未回填前不视为已验。
- 本地样本记录仅保存在浏览器中，不上传，不要求填写真实姓名与联系方式。
- 八字排盘默认使用本地 `lunar_python` 通行历法口径，流派差异待复核。
- 使用前请阅读 [用户协议与免责声明](AGREEMENT.md)。
