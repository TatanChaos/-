# 颐真书房 · 符号映射沙盘

一个认识自己的文化研究工具：不替你解命盘，教你自己把自己解开。

## 这是什么

- 一个可交互的干支符号沙盘：地支六合、三合、六冲、六害、三刑，以及天干五合。
- 生活衔接卡：12 类现实事件，从生活进入符号。
- 自己解开自己：自读五步 + 公开知识。
- 真实样本站：四句话提交，真实结果回填。
- 八字排盘：支持出生时间输入，本地历法库计算。
- 一份“拓展面候选”文档：把传统本义转成结构功能、现代系统对应、可验证假设。
- 所有内容均为文化研究底稿，不是命理定论，不作预测、医疗、法律、投资或重大决策依据。

## 定位

- 不是许愿池，是样本站。
- 大白话和专业话同时给够、给到位。
- 候选解给够，留白给读者自己你的批注。
- 真实样本回填前，一切视为候选。

## 运行

本目录可以直接打开 `index.html`，但文档阅读器在 `file://` 下会回退到 Markdown 原文。完整服务端体验推荐使用：

```bash
node server.js
```

然后访问 `http://127.0.0.1:8780/`。

组合盘在服务端模式下按页计算，不把全部组合一次性塞给浏览器；`file://` 下自动回退到前端分页。
服务状态可查：`http://127.0.0.1:8780/api/status`。
本地样本箱：提交的样本写入 `data/samples-inbox.ndjson`，不会进公开页面，也不会被 Git 追踪。
样本字段含验证状态、判断方法、复盘与评分，形成“方法 → 结论 → 回测 → 反哺”的闭环。
公开部署步骤见 [docs/部署说明.md](docs/部署说明.md)。
本地测试结果见 [docs/本地测试报告_2026-08-12.md](docs/本地测试报告_2026-08-12.md)。
开发者入口见 [docs/开发者指南.md](docs/开发者指南.md)。
English developer guide: [docs/DEVELOPER.md](docs/DEVELOPER.md).

## AI 层

- 当前已提供“再深一层”本地规则深解，免费、不传数据。
- Ollama 本地模型待网络改善后接入，作为可选的 AI 换说法/追问层。
- 安装参考：`ollama pull qwen2.5:3b`，模型就绪后 `server.js` 会自动识别 `ollama` 命令。

也可以使用原来的纯静态服务：

```bash
python3 -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/`。

## 校验

```bash
node tests/verify.mjs
```

校验 22 个天干地支字段、60 组甲子、30 组纳音、组合引擎与隐私边界。

```bash
npm run smoke
npm run audit
```

冒烟测试会启动随机端口服务，检查关键页面、数据文件和组合 API；稽古审计会扫描仍待复核的出处。

## 边界

- 现代系统映射全部属于“拓展面候选”，不冒充物理或医学结论。
- 可验证假设需要真实样本回填，未回填前不视为已验。
- 本地样本记录仅保存在浏览器中，不上传，不要求填写真实姓名与联系方式。
- 八字排盘默认使用本地 `lunar-typescript` 通行历法口径，流派差异待复核。
- 使用前请阅读 [用户协议与免责声明](AGREEMENT.md)。
