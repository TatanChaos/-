# 符号映射沙盘

把天干地支转成现代系统语言的可交互学习工具。

## 功能

- 十二地支 / 十天干切换
- 六合、三合、六冲、六害、三刑关系
- 现代系统映射、现实例子、可验证假设、验证方法
- 本地底稿与原文锚定状态

## 使用

直接打开 `index.html`，或用任意静态服务器托管。

## 状态

本项目内容属于拓展面候选，不代表已验证结论；涉及原文、流派、命理判断处需逐条复核。

## 目录

- `index.html`：交互沙盘
- `docs/十二地支详解.md`：十二地支底稿
- `docs/十天干详解.md`：十天干底稿
