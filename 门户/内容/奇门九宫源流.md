# 奇门九宫源流

日期：2026-08-11
性质：内容初稿 · 拓展面候选

## 人话

奇门像沙盘推演：把时间、方位、角色放进九宫格，看当前局面的关键通道与阻力点。

## 原文核心

- 洛书九宫是基础结构，与后天八卦、方位、节气关联。
- 值符代表当前局面的主控星，值使代表关键通道。
- 门、星、神共同构成一个盘面的信息层。
- 年家、月家、日家、时家四层盘分别对应不同时间尺度。
- 空亡、马星等用于标记结构缺位与动态触发。

## 现代结构

- 九宫：空间与角色网格。
- 值符/值使：负责人与关键通道。
- 门星神：状态、节奏、外部干扰。
- 四层盘：年、月、日、时四种观察尺度。
- 空亡：盲区或条件缺失。

## 可验证假设

1. 同一事件、同一置闰口径排盘，结构应可复现。
2. 四层盘之间的关系需要真实事件样本对照，不能只凭一局下结论。
3. 置闰与茅山等口径差异必须显式标注。

## 边界

- 不作预测、医疗、法律、投资或重大决策依据。
- 门星神格局属于结构观察，不构成绝对断语。
- 真实样本回填前，所有映射均为候选。
