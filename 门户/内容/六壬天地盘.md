# 六壬天地盘

日期：2026-08-11
性质：内容初稿 · 拓展面候选

## 人话

六壬像流程推演：从起点、经过路径、到结果，三传就是那条路径链。

## 原文核心

- 月将加时建立天地盘，表示时间与空间的关系。
- 四课从日干、日支展开，给出事态环境信息。
- 三传表示事态从起点到结果的演变路径。
- 720 课表固化不同干支组合下的三传结构。
- 课体如重审、涉害、别责等，描述路径类型。

## 现代结构

- 天地盘：基准坐标系。
- 四课：输入条件与环境信息。
- 三传：路径链，即起点、中转、落点。
- 720 课表：结构规则库。
- 课体：路径类型标签。

## 可验证假设

1. 同一时间、同一流派口径排盘，课体与三传应可复现。
2. 深浅派与孟仲季派等差异必须显式标注，不能隐藏覆盖。
3. 课体与真实事件结构的关系需要样本回填验证。

## 边界

- 不作预测、医疗、法律、投资或重大决策依据。
- 初传空亡等只是结构标记，不是绝对吉凶。
- 未历法校准、未时辰锚定前，不进入交付断言。
